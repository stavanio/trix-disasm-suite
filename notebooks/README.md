# Development Notebooks

These Colab notebooks document the full development trajectory of TRiX,
including failed attempts, debugging sessions, and iterative refinement.

- **TRiX_Development.ipynb** — Main development notebook. Includes PyBullet
  setup attempts, NumPy physics migration, validation suite runs, figure
  generation, and learning curve experiments. Contains both successful
  runs and dead ends.

- **early_pybullet_experiments.ipynb** — Initial PyBullet experiments with
  three disassembly primitives. Documents the early physics integration
  work that motivated the self-contained simulation approach.

These are raw working notebooks, not polished tutorials. They reflect
the actual research process.
